# AI News Automation

## Overview
An AI-powered news automation workflow built using
n8n and Google Gemini.

## Features
- Automated news processing
- AI-powered news analysis
- Summarization of important news
- Selection of top news stories
- HTML output generation

## Tools Used
- n8n
- Google Gemini
- AI-powered text processing
- HTML

## Setup Instructions
1. Download the workflow JSON file.
2. Import it into your n8n instance.
3. Configure your own Google Gemini API credentials.
4. Configure any additional required nodes.
5. Test the workflow before activating it.

## Security
API keys and credentials must be configured securely
in n8n. Never publish API keys or passwords.
